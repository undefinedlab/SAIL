# 📜 Contract

> **Solidity smart contract — Ethereum Sepolia**

The SAIL contract is the trust anchor of the entire system. It enforces commit-before-execute at the EVM level, stores the on-chain record of every agent commitment, and is queried by Lit Protocol to gate decryption access.

**Deployed:** [`0xaA99758ccD80E8CA9b2142950B04702ff9633990`](https://sepolia.etherscan.io/address/0xaA99758ccD80E8CA9b2142950B04702ff9633990)

---

## Architecture

```
AI Agent (via MCP or REST)
    │
    ├── register()   ← stake ETH, set tier + auditors
    ├── commit()     ← anchor keccak256(encrypted_blob) + 0G CID
    ├── execute()    ← gate reverts if no prior commit
    │
Auditor
    ├── isAuthorized()  ← Lit Protocol queries this before decryption
    └── slash()         ← stake transferred to auditor on mismatch
```

## Contract: `SAIL.sol`

### Data Structures

```solidity
enum Tier { Optimistic, ZK, TEE }

struct Agent {
    address wallet;         // Registered operator wallet
    uint256 stake;          // Locked ETH — slashed on mismatch
    Tier tier;              // Declared trust tier
    bool active;            // False after slash
    address[] auditors;     // Addresses that can audit + slash
    uint256 commitmentCount;
    uint256 slashCount;
}

struct Commitment {
    bytes32 inputHash;      // SHA256 of all inputs before reasoning
    bytes32 commitmentHash; // keccak256 of encrypted blob
    string cid;             // 0G Storage root hash of the blob
    uint256 nonce;          // Agent nonce at commit time
    uint256 timestamp;
    bool executed;
}
```

### Key Functions

| Function | Access | Description |
|----------|--------|-------------|
| `register(ens, tier, auditors)` | Anyone (payable ≥ 0.01 ETH) | Register a new agent |
| `addStake(ens)` | Agent operator | Top up stake |
| `updateAuditors(ens, auditors[])` | Agent operator | Update auditor list |
| `commit(ens, commitmentHash, inputHash, cid)` | Agent operator | Anchor commitment on-chain |
| `execute(ens, commitmentHash)` | Agent operator | Clear execute gate (reverts if no prior commit) |
| `slash(ens)` | Authorized auditor | Slash stake — agent permanently deactivated |
| `isAuthorized(auditor, ens)` | View (public) | Called by Lit Protocol before decryption |
| `getAgent(ens)` | View | Read full agent struct |
| `getCommitment(hash)` | View | Read full commitment struct |
| `getNonce(ens)` | View | Current agent nonce |
| `getAuditors(ens)` | View | Auditor list |

### Execute Gate Logic

```solidity
function execute(string calldata ens, bytes32 commitmentHash) external onlyActiveAgent(ens) {
    Commitment storage c = commitments[commitmentHash];
    if (c.commitmentHash != commitmentHash) revert SAIL__CommitmentNotFound();
    if (c.executed) revert SAIL__AlreadyExecuted();
    if (c.nonce >= nonces[ens]) revert SAIL__NonceMismatch();
    c.executed = true;
    agents[ens].commitmentCount++;
    emit ExecutionCleared(ens, commitmentHash);
}
```

Three invariants enforced atomically:
1. Commitment exists on-chain (not fabricated post-hoc)
2. Not already executed (no replay)
3. Nonce precedes current nonce (posted before this call)

### Custom Errors

| Error | When |
|-------|------|
| `SAIL__NotOwner` | Caller is not contract owner |
| `SAIL__AlreadyRegistered` | ENS name already registered |
| `SAIL__InsufficientStake` | Stake below 0.01 ETH minimum |
| `SAIL__AgentNotActive` | Agent slashed or not registered |
| `SAIL__CommitmentNotFound` | Commitment hash not on-chain |
| `SAIL__AlreadyExecuted` | Commitment already used for execution |
| `SAIL__NonceMismatch` | Replay attack detected |
| `SAIL__NotAuthorizedAuditor` | Caller not in auditor list |
| `SAIL__CommitmentAlreadyExists` | Duplicate commitment hash |
| `SAIL__TransferFailed` | ETH transfer to auditor failed |
| `SAIL__NotAgentOperator` | Caller is not the registered wallet |
| `SAIL__NoAuditors` | Empty auditor list |

## Security

- **`ReentrancyGuard`** on `slash()` — the only function that transfers ETH
- **Checks-effects-interactions** pattern in `slash()` — stake zeroed before transfer
- **Custom errors** — no string revert messages (gas efficient, unambiguous)
- **No upgradability** — immutable deployment, no proxy pattern
- **Minimum stake** — 0.01 ETH constant enforced at registration
- **Nonce ordering** — prevents commit replay and out-of-order execution
